# STS-2300-Project
R Code to Analyse World Fair Data From Wikipedia 

Graphs R is basic code for formatting a graph with scales and labs labels. The starter code is code for pulling the Wikipedia data into R and into one cohesive dataframe. The stats project file is the actual code for cleaning and creating the graphs.

Data from: https://en.wikipedia.org/wiki/World%27s_fair#List_of_expositions
